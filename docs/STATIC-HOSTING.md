# Static and Shared hosting

For Hostinger Shared, use the PHP + MySQL deployment guide in [HOSTINGER-SHARED.md](HOSTINGER-SHARED.md). The PHP API is deployed on the same domain as the HTML portals and preserves the existing API routes.

The earlier FastAPI static-hosting approach is retained only as historical reference for deployments that intentionally run the Python backend elsewhere. It is not required for the Hostinger Shared architecture.
